# 复查与改进记录（2026-10-23）

## 结论

当前适合作为有明确业务约束、工具调用和恢复机制的简历演示项目；仍不能当作支持任意中文输入、真实商家履约、生产身份认证的上线系统。核心学习材料见 [完整入门与面试手册](LEARNING-AND-INTERVIEW-HANDBOOK.md)。

## 本轮找到并修复的问题

1. **部分撤销误清全部饮食要求**：原逻辑只要识别到撤销且没有新饮食要求就清空整个 pending 列表。现在逐项匹配撤销主题，取消零乳糖不再清除坚果过敏；复合要求有歧义时继续保留。新增真实 MySQL 多轮测试。
2. **否定撤销被当成撤销**：“刚才的要求不要取消”不再清空要求；“不要取消预算／送达限制／商品限制”保留原快照并请求明确说明，不放宽硬约束。
3. **中文金额缺单位被误解释**：“一百二”曾被按 102 处理；“一二”“十十”等也可能被错误累计。现在要求明确数字或单位，不静默猜测。修正中文负小数符号处理。
4. **入门文档入口过时**：原 getting-started 把 Agent 端口与 Java 控制台混用，现在明确两条路径，新增从启动到事务、故障恢复、评测和面试的学习手册。
