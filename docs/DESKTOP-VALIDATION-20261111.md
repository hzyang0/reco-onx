# 电脑端专项模拟验证（2026-11-11）

本轮只检查电脑浏览器和后端，不开展微信相关工作。浏览器为 Chromium，视口 1440×1000。

## 发现并修复

旧账号长期偏好的 HTTP 响应晚于退出／新账号登录返回时，会覆盖新账号的偏好面板。受控延迟下修复前测试失败，修复后通过。同样为历史读取加上 token + session 比较，避免旧对话覆盖新页面。

登录、会话恢复及新建会话的异步结果也校验当前身份／操作代次。多标签页发生共享账号变更时，其他标签页清除旧展示并返回画像选择；重试请求改为按用户和会话分别存储，避免全局单槽覆盖。完成这些变更后桌面浏览器专项回归再次通过。

专项复现：

```sh
CHROMIUM_PATH=/usr/bin/chromium node scripts/check-desktop-isolation.cjs
CHROMIUM_PATH=/usr/bin/chromium node scripts/check-agent-ui.cjs
```

需要 Playwright、Chromium 和正在运行的模拟 Agent / MySQL / Redis。可用 AGENT_URL 指定地址。全部使用演示画像和合成目录，历史记录会保留。迟到响应使用合成私有标记；弱网重试则实际执行真实工具和任务持久化，只丢弃第一次完成事件。

本轮不声称任意语言、真实商家、真实用户体验或所有浏览器已验证。旧版全局重试槽不再自动读取，升级前尚未完成的旧请求应先查询服务端结果再重新发起；新版本按会话保存待重试记录。
