# 主持人观察与判分（不要提前给参与者）

每人使用匿名编号，记录背景、任务编号、开始/结束时间、原话、每轮系统输出和主持人帮助。不要替参与者改写句子后再提交。系统未理解时，不要马上教它“正确提示词”；先记录失败，然后允许继续。

结果分为：独立完成、帮助后完成、放弃、系统错误。任务6中正确承认无法确认即为完成。任务2中“接受更贵”“不限款式”等明确选择可有多种合理结局；按参与者最终授权的约束判分，不强求唯一措辞。

额外观察：是否把标价当总价；是否注意报价有效期；是否理解“无匹配”和“工具失败”的区别；是否知道修改哪项要求；是否注意到系统漏掉条件；多轮后是否仍相信结果。把你的解释和参与者原话分栏保存。

问题归类：解析遗漏、错误放宽、商品替代、费用错误、时间/区域错误、记忆冲突、不必要澄清、页面理解、系统故障。先记录证据，再决定修复方向。

先导试用不承诺固定成功率阈值；发布到真实用户前至少应做到该轮没有未解释的硬约束违反，以及常见任务无需主持人教特定句式。每次报告同时注明参加人数、尝试任务数、帮助次数和数据范围。
