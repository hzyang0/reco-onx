# 试用任务卡（发给参与者）

这是一套校园本地生活推荐演示，数据是合成的，不会真实下单。支持北区、南区、东区，以及咖啡、简餐、便利食品；一次比较一种商品，可买多件。

请用你平时会说的话描述需求，不必模仿示例。系统可能误解你，你可以指出、修改条件或放弃。我们想知道产品哪里不好用，不是在测试你。每项任务请新建对话，任务内部的追问留在同一对话。

1. 你在北区，想买一杯咖啡。包括包装和配送，最多花20元，半小时内送到。找到最便宜的可行方案，并说说为什么选它。
2. 你在北区只想喝拿铁，一杯总预算30元。得到结果后把预算降低到20元，其他要求不变。看看系统怎么处理；然后自行决定是否放宽一项要求。
3. 你在北区，想买两杯拿铁，包含所有费用最多35元，20分钟内送到。检查结果有没有少算或漏算费用。
4. 你在南区，想买一杯咖啡，总预算20元，30分钟内送到。没有合适结果时，看看你能否理解原因并继续完成任务。
5. 你在东区，想买一份简餐，总预算30元，一小时内送到。拿到结果后改成送往北区，其他要求不变。
6. 假设你要帮一位对坚果过敏的人买零食。试着向系统表达，并判断系统有没有可靠依据保证这项要求。这里不需要你提供任何真实健康信息。

最后请告诉主持人：最困惑的一处是什么？你会不会再用？如果只能改一件事，你希望改什么？
